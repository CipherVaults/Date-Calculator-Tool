## ⚖️ Conflict rules

1. The owner's latest explicit instruction wins, then `0- FROZEN_DECISIONS.md`, then specs 1–3.
2. Source code and fixtures win over descriptive docs for *what the code does*; docs are corrected, not the other way round, unless the owner decides otherwise.
3. Notion mirrors the repository; on disagreement the repository records are authoritative.
